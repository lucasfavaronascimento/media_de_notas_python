# 📊 Media de Notas do Aluno

## 🔩 Como Funciona
* Um script simples em Python usado para calcular a média de um aluno baseado em duas notas inseridas pelo usuário e exibir se ele foi aprovado ou reprovado.

## 🛠️ Tecnologias Utilizadas

* Linuagem de programação Python 

## 🚀 Funcionalidades

* 📥 Registrar a primeira e segunda nota.
* 🧮 Cálcula automáticamente a média final.
* 🚦 Validação de status: "Aprovado" caso a média seja de 7.0, caso seja menor será "*Reprovado".

### 🔧 Como Executar o Projeto

1. Baixe o arquivo `app.py`.
2. Abra o software na pasta do arquivo e execute o comando:

```bash
python app.py
```
